## 2. جدول توصيف حالات الاستخدام (Detailed Use Cases Specification)

### أ) الزائر (Guest / Visitor)
| المعرف | اسم حالة الاستخدام | الوصف الفني المعتمد | الشروط المسبقة (Pre-conditions) |
| :--- | :--- | :--- | :--- |
| **UC-01** | **تصفح المزادات والمناقصات** *(Browse Listings)* | استعراض كافة السلع والفرص التجارية المعروضة وقراءة التفاصيل والأسعار | اتصال نشط بالإنترنت |
| **UC-02** | **البحث والتصفية المتقدمة** *(Search & Filter)* | تصفية السلع والمناقصات حسب المحافظة، النطاق السعري، والتصنيف التجاري | لا يوجد |
| **UC-03** | **التسجيل ودخول الحساب** *(Register / Login)* | إنشاء حساب جديد برقم هاتف محلي أو تسجيل الدخول السريع | رقم هاتف غير مسجل مسبقاً |

### ب) المستخدم المسجل (Registered User - بائع ومشتري ومورد)
> *(يرث المستخدم تلقائياً صلاحيات الزائر: التصفح والبحث).*

| المعرف | اسم حالة الاستخدام | الوصف الفني المعتمد | الشروط المسبقة (Pre-conditions) |
| :--- | :--- | :--- | :--- |
| **UC-04** | **إدارة الملف الشخصي** *(Manage Profile)* | تعديل البيانات الشخصية وتغيير كلمة المرور وتفضيلات التنبيهات | تسجيل الدخول |
| **UC-05** | **إدارة المحفظة والضمان** *(Wallet & Escrow)* | شحن الرصيد بسندات الإيداع ومتابعة حركة المبالغ المحجوزة بالضمان | حساب مسجل |
| **UC-06** | **المزايدة وتقديم العروض** *(Submit Bid / Offer)* | تقديم عروض المزايدة اللحظية أو عروض التوريد للمناقصات | رصيد كافٍ بالمحفظة |
| **UC-07** | **طرح مزاد أو مناقصة** *(Publish Listing)* | نشر إعلان بيع بالمزاد العلني أو طرح طلب توريد تجاري مباشرة | حساب مسجل |
| **UC-08** | **معاينة واستلام السلعة** *(Inspect & Receive - 48h)* | نافذة فحص مدتها 48 ساعة لمطابقة السلعة مع التقرير قبل صرف المبلغ للبائع | الفوز بالصفقة وسداد القيمة |
| **UC-09** | **المفضلة وتقييم التعامل** *(Watchlist & Rate)* | حفظ السلع للمتابعة وتقييم مصداقية الطرف الآخر بعد اكتمال الصفقة | حساب مسجل |

### ج) مدير النظام (Platform Admin - رقابة وإشراف مستقل)
| المعرف | اسم حالة الاستخدام | الوصف الفني المعتمد | الشروط المسبقة (Pre-conditions) |
| :--- | :--- | :--- | :--- |
| **UC-10** | **إدارة حسابات المشتركين** *(Manage Users)* | تفعيل الحسابات، مراجعة النشاط، وحظر الحسابات المخالفة للائحة | صلاحيات المشرف العام |
| **UC-11** | **إدارة المزادات والمناقصات** *(Manage Listings)* | متابعة غرف المزايدة الحية، تجميد أو استئناف الغرف، وإغلاق الصفقات | صلاحيات إدارة العمليات |
| **UC-12** | **تدقيق السندات والعمولات** *(Finance Audit)* | مطابقة سندات البنوك وشحن محافظ المستخدمين واحتساب عمولة 2.5% | صلاحيات المشرف المالي |
| **UC-13** | **فض النزاعات والتحكيم** *(Resolve Disputes)* | إدارة محادثة التحكيم الثلاثية وإصدار أحكام ملزمة بالإرجاع أو الصرف | وجود نزاع مفتوح من المشتري |
| **UC-14** | **مراقبة الأمان ومكافحة التلاعب** *(Security & Anti-Fraud)* | رصد المزايدات المشبوهة، كشف تقارب عناوين IP، وحظر أجهزة حسابات الظل | صلاحيات المشرف الأمني |

## 3. قواعد العلاقات التفاعلية المعتمدة (Include & Extend)

### 1. علاقة التضمين الإجبارية (`<<include>>`):
- **`Submit Bid / Offer` $\xrightarrow{\text{<<include>>}}$ `Hold Deposit`**:  
  *السبب*: لا يُقبل أي عرض مالي أو مزايدة إلا بحجز تأمين الجدية آلياً من محفظة المشترك.

### 2. علاقات التمديد الشرطية (`<<extend>>`):
- **`Extend Time` $\xrightarrow{\text{<<extend>>}}$ `Submit Bid / Offer`**:  
  *نقطة الامتداد*: **إذا وفقط إذا** قُدمت مزايدة في آخر 120 ثانية من عمر المزاد (تمديد تلقائي Anti-Sniping).
- **`Open Dispute` $\xrightarrow{\text{<<extend>>}}$ `Inspect & Receive`**:  
  *نقطة الامتداد*: **إذا وفقط إذا** تبيّن للمشتري وجود عيب جوهري غير مطابق للفحص خلال مهلة الـ 48 ساعة.
