# منصة مزايد (Mozaid AI) 🏆
### أول منصة مزادات ومناقصات حية ذكية متوافقة مع السوق اليمني

منصة متكاملة تجمع بين **المزادات التصاعدية (Forward Auctions)** للسلع والأصول (عقارات، سيارات، إلكترونيات، بضائع) و**المناقصات التنافسية العكسية (Reverse Tenders)** للمشتريات والتوريدات، مدعومة بنماذج **الذكاء الاصطناعي (AI)** لكتابة المواصفات وكشف الاحتيال، مع معمارية دفع وتوثيق مالي مصممة خصيصاً للبيئة اليمنية.

---

## 📚 وثائق المشروع الرسمية (Project Blueprint)

تم إعداد وتوثيق كافة تفاصيل المنصة في مجلد [`docs/`](./docs/):

1. **[وثيقة متطلبات المنتج (PRD.md)](./docs/PRD.md):**
   - الرؤية والجمهور المستهدف (C2C, B2C, B2B).
   - توطين النظام لليمن وحل معضلة الدفع والتوثيق.
   - تفصيل وظائف الذكاء الاصطناعي الثلاث: (توليد كراسات الشروط، المطابقة الذكية، درع كشف المزايدات الوهمية Anti-Shill).
   - هيكل لوحة الإدارة المتكاملة (Live Command Center، مركز التدقيق المالي والمحافظ، مركز مكافحة الاحتيال، إدارة النزاعات).
   
2. **[حالات الاستخدام والسيناريوهات (USECASES.md)](./docs/USECASES.md):**
   - تفصيل 10 حالات استخدام دقيقة مع خطوات المسار الأساسي والبديل وتدفقات الشاشات.

3. **[سكيما قاعدة البيانات ومخطط الكيانات (DATABASE_SCHEMA.sql & .md)](./docs/DATABASE_SCHEMA.sql):**
   - كود SQL متكامل لـ PostgreSQL مع الجداول والفهارس والإجراءات التلقائية (Triggers) والعلاقات المنطقية.
   - مخطط ERD بالـ Mermaid وشرح استراتيجية الفهارس للأداء العالي بالوقت الفعلي.

4. **[دليل المشاريع مفتوحة المصدر والمرجعيات (OPEN_SOURCE_REFERENCES.md)](./docs/OPEN_SOURCE_REFERENCES.md):**
   - تحليل مستودعات GitHub التي تختصر 60-70% من العمل (Next-Auctions, BidFlow, OpenProcurement, BidMaster-Pro).

## 🛠 المعمارية والستاك التقني (Tech Stack)

* **الواجهة الأمامية وتطبيق الهاتف:** Next.js 15 (React 19) + PWA (Progressive Web App) خفيف وسريع الاستجابة + Tailwind CSS.
* **الوقت الفعلي والبث المباشر (Real-Time):** WebSockets / Supabase Realtime لبث العطاءات في أجزاء من الثانية.
* **محرك الذكاء الاصطناعي (AI Layer):** Google Gemini API (Multimodal Vision & Structured Outputs) لتوليد المواصفات ومطابقة العروض وتحليل شبهات التلاعب.
* **قاعدة البيانات والتخزين المؤقت:** PostgreSQL + Redis (لحسابات التوقيت وطوابير المزايدة ومنع التعارضات).
* **إدارة الضمان والدفع (Escrow & Yemeni Rails):** نظام حسابات وسيطة معتمد لمحفظة الكريمي، ون كاش، جوالي، وشبكات النجم والعمقي مع فحص سندات الإيداع المرفوعة.

## 🚀 البدء السريع (Quickstart)

```bash
# 1. نسخ ملف البيئة وضبط المتغيرات
cp .env.example .env.local

# 2. تثبيت الحزم البرمجية
npm install

# 3. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
